# VentureMatch

A serious co-founder matching app (Android first).

## Repository Structure

- `/backend`: Node.js, Express, TypeScript, Prisma, MySQL 8, Zod, Socket.IO, JWT.
- `/mobile`: Expo dev build, TypeScript, Expo Router, TanStack Query, React Hook Form + Zod, Zustand, FlashList.
- `/docs`: Architecture, design rules, and API specifications (`/docs/api.md`).

## Quick Start (Backend)

Refer to [`/backend/README.md`](./backend/README.md) for full setup, database migrations, seeding, and verification commands.
